# Applied ML for CO2 Adsorption on Biomass-Derived Porous Carbons

Reproducing the machine learning workflow from:
> *Yuan et al., "Applied Machine Learning for Prediction of CO2 Adsorption on Biomass Waste-Derived Porous Carbons", Environ. Sci. Technol. 2021.*

## Workflow
- Models: Gradient Boosting (GBDT), XGBoost, LightGBM
- Features: 9 input features (3 textural, 4 compositional, 2 process parameters)
- Analysis: Permutation Feature Importance & Partial Dependence Plots (PDP)
